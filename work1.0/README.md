# 模藏账本微信小程序

用于记录模型、手办及相关产品的预订、补款和全款消费。项目使用微信小程序 TypeScript + Less 和微信云开发。

## 首次运行

1. 用微信开发者工具导入本目录。
2. 点击“云开发”并创建一个云环境；`app.ts` 使用当前默认环境。
3. 在云数据库创建 `purchases` 和 `users` 两个集合。
4. 将两个集合的权限都设置为“仅创建者可读写”。不要设置为所有用户可读。
5. 在开发者工具中右键 `cloudfunctions/login`，选择“上传并部署：云端安装依赖”。
6. 重新编译项目。

数据库在客户端新增记录时会自动写入 `_openid`。集合权限负责确保登录用户只能读取、更新和删除自己的数据。

## 已实现

- 微信云开发身份识别和多用户数据隔离
- 消费记录新增、编辑、删除
- 预订、补款、全款三种付款类型
- 日期区间查询与区间合计
- 月度消费折线图
- 用户头像、昵称和记录数量

金额以“分”为单位存入数据库，避免浮点数计算误差。
